## 📖 О проекте

**QezVM** — это стековая виртуальная машина, написанная на C (стандарт C11). Она создана для выполнения байт-кода, который генерирует компилятор **[QCC](https://github.com/QeZzhi/QCC)** из исходного кода на языке **Qora**.

**Зачем это нужно?**
Вместо того чтобы компилировать Qora напрямую в машинный код под каждую конкретную платформу (macOS, Linux и т.д.), мы компилируем его в универсальный байт-код. QezVM берет на себя всю работу по его исполнению. Это позволяет запускать один и тот же код на любом устройстве, где есть QezVM, не переписывая компилятор.

## 🏗 Архитектура VM

QezVM — это классическая стековая машина. Вот её основные компоненты:

*   📦 **Стек операндов (Operand Stack):** Главный рабочий инструмент. Все математические операции и вызовы функций происходят через него.
*   🧠 **Память (Memory):** Выделенная область для хранения глобальных переменных и кучи (heap).
*   🎯 **Регистры управления:** Счетчик команд (`IP` — Instruction Pointer) и указатель стека (`SP` — Stack Pointer).
*   ⚡ **Набор инструкций (ISA):** Поддержка базовых операций (арифметика, логика, переходы, работа со стеком).

## 🚀 Как собрать и запустить

1. Собери проект с помощью `make`:
   make

2. Запусти виртуальную машину, передав ей скомпилированный файл `.qc` (его создает QCC):
   ./qezvm <файл.qc>
   *По умолчанию VM работает в тихом режиме и выводит только результат работы программы.*

3. **Режим отладки (флаг `-v`):**
   Если тебе нужно увидеть, как загружается файл, сколько байт занимает код, и когда VM завершает работу, используй флаг `-v` (или `--verbose`):
   ./qezvm -v <файл.qc>
   В этом режиме ты увидишь логи загрузчика (`Loaded... bytes`) и сообщение о завершении (`VM Halted`).
